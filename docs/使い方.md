# 使い方

## 最初の 1 回だけ

1. iPhone の Safari で `https://asih-collab.github.io/cashflow-app/` を開く
2. 画面下の「共有」ボタン（四角から矢印が出ているマーク）→「ホーム画面に追加」→ 右上の「追加」
3. ホーム画面に増えた「家計」のアイコンから開く（次からはここから）
4. 「ログインする」→ メールアドレスを入れて「ログイン用のメールを送る」
5. 件名「ログイン用コード」のメールに書かれた 6 桁の数字を、アプリに入力する（6 桁そろうと自動でログイン）
   - メールが届かないときは迷惑メールフォルダを確認。見つけたら「迷惑メールではない」にしておくと次から届きやすい
   - メールのリンクを押して Safari が開いた場合は、そこの「ログイン情報をコピー」→ アプリのログイン画面の「メールのリンクを Safari で開いた場合」に貼り付けてもよい

ログインしなくても記録はできます（iPhone の中だけに保存）。ログインすると自動でバックアップされ、機種変更しても URL を開いてログインすれば戻ります。

## 毎回の記録（3 タップ）

1. アイコンを押すと数字のキーが出る。金額を押す
2. カテゴリ（デート・外食・食料品…）を押す
3. 「保存」を押す

- 日付は今日、支払い手段は前回と同じが自動で入る。変えたいときだけ「詳細」を開く
- 上に出ていないカテゴリは「その他…」から選ぶ
- 間違えたら、保存直後に出る「取り消す」か、ホームの「最近の記録」の「削除」
- 電波が無くても保存できる。あとで自動で送られる

## 予算（今月あといくら使えるか）

1. ホームの「予算を決める」、またはサマリの「予算を設定」を押す
2. 食費・交際費など大分類ごとに、この月に使ってよい額を入れる（右に前の月の実績が出ます）
3. ホームの大きな数字が「あと使える額」に変わり、「PER DAY」に残り日数で割った 1 日あたりの額が出ます
- 大分類ごとの残りもホームに並びます。予算の 8 割を超えた瞬間に、記録したときに「注意」が出ます
- 翌月は「前の月の予算をコピー」で同じ予算を使えます

## 固定費・給料の自動記録

1. 設定 →「固定費・定期の収入」→「追加する」
2. 名前・金額・毎月の日付・カテゴリを入れて保存（給料は上の「収入」を選ぶ）
- 毎月 1 回だけ自動で記録されます。その月の分は月初に、予定の日付で記録されます（履歴に「予定」と出ます）
- 光熱費のように毎月変わるものは「金額は毎月確認」をオンにし、明細が来たら履歴から金額を直します
- 「自動記録をやめる」で翌月以降は記録されなくなります（これまでの記録は残ります）

## サマリ（月末の振り返り）

- 下のタブの「サマリ」で、その月の 収入・支出・収支（黒字か赤字か）が出ます。支出には固定費・返済・積立も入ります
- カテゴリごとの実績と予算、前の月との差（前月比）も見られます。左右の矢印で月を切り替えます
- カテゴリの行を押すと、中分類ごとの金額（外食・コンビニなど）とその月の記録の一覧が開きます。記録を押すと修正できます
- 「支出の内訳」の 変動費・準固定費・固定費 の行を押すと、含まれるカテゴリと割合が開きます。カテゴリを押すと、その詳細へ移ります

## 履歴（カレンダー）

- 下のタブの「履歴」で、その月のカレンダーが出ます。各日のマスにはその日の収支（収入 − 支出）だけが出ます。赤字の日は朱色、黒字の日は「+」付きの緑です。1 万円以上は「2.1万」のように短く表示します
- 上の段に、その月の収支（黒字・赤字）、収入、支出の合計が出ます
- 日付を押すと、下にその日の収入・支出・収支と記録の一覧が開きます。記録を押すと修正、「支出を追加」「収入を追加」でその日付の記録を登録できます。保存するとカレンダーの同じ日に戻ります
- まだ来ていない日（家賃などの予定）は薄く表示されます。左右の矢印で月を切り替えます
- 上の「一覧」に切り替えると、その月の記録を新しい日から順にすべて並べて見られます。日ごとの収支と、月初からの累計（給料が入って、何にどれだけ出ていったか）が出ます。「支出」「収入」で絞り込めます。記録を押すと修正できます。最後に選んだ表示（カレンダー / 一覧）を覚えています

## 日別の支出

- ホームの「日別 / DAILY」に、今月の毎日の変動費が棒グラフで出ます。細い横線は 1 日あたりの平均です
- 棒を押すと、その日の合計と明細がグラフの下に出ます（最初は今日）
- 「一覧で見る」を開くと、使った日を数字の一覧で確認できます

## 記録の修正・削除

- ホームの「最近の記録」の行、または日別グラフの下の明細を押すと修正画面が開きます
- 金額・カテゴリ・支出と収入の切り替えはそのまま押して直せます。最初に数字を押すと金額を入れ直します
- 日付・支払い手段・メモは「詳細」を開いて直します
- 「〜に更新」を押すと保存。直後に出る「元に戻す」で修正前に戻せます
- 右上の「削除」でその記録を消せます（直後の「元に戻す」で復活）

## 記録のコピー（同じ内容をもう一度入れる）

- ホームの「最近の記録」と、履歴で日付を押したときの記録の一覧にあるコピーのボタン（四角が 2 つ重なった印）、または修正画面の右上「コピー」を押します
- 金額・カテゴリ・支払い手段・メモが入った記録画面が開きます。日付は今日です（「詳細」で変えられます）
- そのまま「保存」で新しい記録として追加されます。金額だけ違うときは数字を押すと入れ直せます。元の記録は変わりません

## リボ・分割の残高

- 「設定」→「リボ・分割の残高」で、カードごとに「今の残高」「毎月の返済額」「手数料の年率（多くのリボは 15%）」を入れます
- 合計の残高、いつ返し終わるか（完済見込み）、それまでに払う手数料が出ます。ホームにも残高と完済見込みが出ます
- 「返済を増やすと」で、毎月 5,000 / 10,000 / 30,000 円多く返した場合に何か月早く終わり、手数料がいくら減るかをグラフで比べられます。グラフをなぞるとその月の残高が出ます
- ボーナスなどでまとめて返す予定は、カードの行を押した画面の「一括返済の予定」で月と金額を入れます。完済見込みに反映され、その月になるとホームに案内が出ます。返済したら「返した」を押すと、返済の記録が足され、残高もその分減ります（明細の残高と違えば直してください）
- ホームとサマリにも残高のまとめが出ます。毎月の返済のうち「手数料」と「元金（実際に残高が減る分）」がいくらかを帯で表示します
- 固定費の自動記録「リボ・分割返済」の金額は、カードごとの返済額の合計に自動で合わせます（違っている場合は画面に「合わせる」ボタンが出ます）
- 月に 1 回、明細が来たらカードの行を押して「今の残高」を入れ直してください（1 か月以上更新していないと案内が出ます）。入れた残高は「これまでの残高」に残ります

## 通知（記録のリマインド・月末の振り返り）

- ホーム画面に追加したアプリで「設定」→「通知」→「通知をオンにする」を押し、iPhone の確認で「許可」を選びます（Safari で開いている間は使えません）
- 夜 9 時: その日の記録が 1 件もないときだけ届きます
- 予算の月の最終日（給料日の前日）の夜 8 時: 振り返りの案内が届きます。押すとサマリが開きます
- 「テスト通知」で届くか確かめられます。どちらかだけ止めたいときはスイッチで切れます
- iPhone を替えたときや、アプリを入れ直したときは、もう一度オンにしてください

## iPhone のショートカットから記録する（ウィジェット代わり）

ホーム画面やウィジェットから「金額 → カテゴリ」を選ぶだけで記録できます。最初に 1 回だけ作ります。

1. 「ショートカット」アプリを開き、右上の「＋」を押す
2. 「アクションを追加」で「入力を要求」を選ぶ。「プロンプト」を「金額は？」、入力の種類を「数字」にする
3. 次に「メニューから選択」を追加し、項目を「デート」「外食」「食料品」「コンビニ」「その他」にする（よく使うものに変えて構いません）
4. 各項目の中に「URL」アクションを追加し、次の形で入れる（「入力された数字」は変数を選ぶ。カテゴリ名は項目ごとに変える）
   `https://asih-collab.github.io/cashflow-app/#/add?amount=［入力された数字］&cat=デート&save=1`
5. メニューの後に「URL を開く」を追加する
6. 名前を「支出を記録」にして保存。長押し →「ホーム画面に追加」、またはウィジェットに置く

- 開くと、その金額とカテゴリで自動で保存され、予算がある場合は「交際費 残り ¥◯◯」のように出ます
- ショートカットからは Safari で開きます。Safari 側でも一度ログインしておくと、記録はホーム画面のアプリにも同期されます
- 「その他」を選んだ場合は、`cat=` を空にしておけば金額だけ入った記録画面が開き、カテゴリを選んで保存できます

## レシートから記録する

**いちばん簡単: アプリのカメラで撮る**

1. 記録画面の右上「レシート」→「カメラで撮る」
2. レシートを撮る（明るい所で、平らにして画面いっぱいに、真上からまっすぐ）
3. 数秒で合計金額・日付・お店・カテゴリ・支払い手段が入るので、確かめて「確かめて保存」

- 撮った写真は保存されません（カメラロールにも残りません）。文字の読み取りはこの iPhone の中で行い、画像はどこにも送りません
- 初めて使うときだけ、読み取りの部品（約 6MB）を読み込むので少し時間がかかります。2 回目からはすぐです
- 「読み取り: 要確認」のときは「撮り直す」か、金額を確かめて直してください。撮ってあるレシートの写真は「写真から選ぶ」でも読めます

**もっと正確に: iPhone の文字認識を使う**（アプリのカメラで読みにくいレシート向け）

iPhone 自体の文字認識は、アプリ内のカメラより正確です。ショートカット「レシートを記録」を作ると、撮るだけで読み取った内容がアプリに入ります（ショートカットの「写真を撮る」で撮った写真もカメラロールには残りません）。

1. 「ショートカット」アプリを開き、右上の「＋」
2. 「写真を撮る」を追加
3. 「画像からテキストを抽出」を追加（入力は「写真」）
4. 「URL エンコード」を追加（入力は「画像から抽出したテキスト」）
5. 「URL」を追加し、`https://asih-collab.github.io/cashflow-app/#/receipt?text=` の後ろに、変数「URL エンコードしたテキスト」を入れる
6. 「URL を開く」を追加
7. 名前を「レシートを記録」にして保存

- ショートカットからは Safari で開きます。Safari 側でも一度ログインしておくと、記録はホーム画面のアプリにも同期されます
- 写真の「テキスト認識」で文字をコピーして、レシート画面の「もっと正確に」→「貼り付けて読み取る」でも使えます

**読み取った内容の確かめ方**

- 上に「読み取り: 確か / たぶん / 要確認」が出ます。「たぶん」「要確認」のときは金額を見て、違っていれば「ほかの候補」を押すか、入れ直してください
- カテゴリはお店から推測します。一度選んだお店は、次から同じカテゴリになります
- 同じ日・同じ金額の記録がすでにあると、二重にならないよう注意が出ます
- 設定の「レシートの読み取り」に、直さずに使えた割合（金額・日付・カテゴリ）が出ます

## 収入の記録

1. 記録画面の上の「支出 / 収入」で **収入** を押す（色が緑に変わります）
2. 金額を押し、給与・賞与・副業・臨時収入・その他の収入 から選んで保存
- 支払い手段は聞かれません。日付を変えたいときだけ「詳細」を開きます
- ホームの「INCOME」に今月の収入合計が出ます。変動費の合計には入りません
- 給料の毎月の自動記録は、次の段階（予算・固定費の自動記録）で追加予定です

## 今月の気づき（改善アドバイス）

- ホームの「今月の気づき」に、記録と予算から気づいたことを上位 3 件、サマリの「気づき」に全部出します（例: 「このペースだと月末に約◯円の赤字」「食費が予算のペースより速め」「黒字見込みを返済に回すと手数料が◯円減る」）
- それぞれ「役に立った」「立たない」を押してください。月に 1 回、その反応をもとにアドバイスの決まりや言い方を見直します（見直しに使うのは管理者本人のデータだけです）
- 月の初めの数日は記録が少ないので、出ないか、予算をもとにした見込みになります

## ホーム

- 今月の変動費の合計、1 日あたりの平均、中分類ごとの内訳
- 「今月」は暦月。給料日基準（25 日〜翌月 24 日）にしたいときは 設定 →「今月」の始まりの日

## 設定でできること

- 開いたときの画面（記録 / ホーム）
- カテゴリを選んだらすぐ保存（2 タップにする）
- カテゴリの追加・名前の変更・非表示
- 支払い手段の追加・名前の変更（例: 楽天カード、PayPay）
- 記録をすべて JSON で書き出す

## 知人に使ってもらうとき（管理者向け）

1. 使う人のメールアドレスを許可リストに入れる（Supabase の SQL Editor で実行）
   ```sql
   insert into private.allowed_emails (email) values ('相手のメールアドレス');
   ```
2. 相手に URL `https://asih-collab.github.io/cashflow-app/` と、上の「最初の 1 回だけ」の手順を伝える
3. 伝えておくこと
   - 記録（金額・カテゴリ・メモ）は管理者の Supabase に保存され、**管理者は見ようと思えば見られる**
   - 他の利用者の記録は互いに見えない（データベース側で制限）
   - 1 週間誰も使わないと Supabase が一時停止し、次に開いたとき同期に少し時間がかかることがある
4. ログイン用のメールは Brevo（外部のメール送信サービス、無料枠 1 日 300 通）から送っている。差出人が Gmail なので迷惑メールに入りやすい。相手に「届かなければ迷惑メールを見て」と伝える
