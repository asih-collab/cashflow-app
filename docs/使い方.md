# 使い方

## 最初の 1 回だけ

1. iPhone の Safari で `https://asih-collab.github.io/cashflow-app/` を開く
2. 画面下の「共有」ボタン（四角から矢印が出ているマーク）→「ホーム画面に追加」→ 右上の「追加」
3. ホーム画面に増えた「家計」のアイコンから開く（次からはここから）
4. 「ログインする」→ メールアドレスを入れて「ログイン用のメールを送る」
5. 件名「ログイン用コード」のメールに書かれた 6 桁の数字を、アプリに入力する（6 桁そろうと自動でログイン）
   - メールが届かないときは迷惑メールフォルダを確認。見つけたら「迷惑メールではない」にしておくと次から届きやすい
   - メールのリンクを押して Safari が開いた場合は、そこの「ログイン情報をコピー」→ アプリのログイン画面の「メールのリンクを Safari で開いた場合」に貼り付けてもよい

ログインしなくても記録はできます（iPhone の中だけに保存）。ログインすると自動でバックアップされ、機種変更しても URL を開いてログインすれば戻ります。

## 毎回の記録（3 タップ）

1. アイコンを押すと数字のキーが出る。金額を押す
2. カテゴリ（デート・外食・食料品…）を押す
3. 「保存」を押す

- 日付は今日、支払い手段は前回と同じが自動で入る。変えたいときだけ「詳細」を開く
- 上に出ていないカテゴリは「その他…」から選ぶ
- 間違えたら、保存直後に出る「取り消す」か、ホームの「最近の記録」の「削除」
- 電波が無くても保存できる。あとで自動で送られる

## 収入の記録

1. 記録画面の上の「支出 / 収入」で **収入** を押す（色が緑に変わります）
2. 金額を押し、給与・賞与・副業・臨時収入・その他の収入 から選んで保存
- 支払い手段は聞かれません。日付を変えたいときだけ「詳細」を開きます
- ホームの「INCOME」に今月の収入合計が出ます。変動費の合計には入りません
- 給料の毎月の自動記録は、次の段階（予算・固定費の自動記録）で追加予定です

## ホーム

- 今月の変動費の合計、1 日あたりの平均、中分類ごとの内訳
- 「今月」は暦月。給料日基準（25 日〜翌月 24 日）にしたいときは 設定 →「今月」の始まりの日

## 設定でできること

- 開いたときの画面（記録 / ホーム）
- カテゴリを選んだらすぐ保存（2 タップにする）
- カテゴリの追加・名前の変更・非表示
- 支払い手段の追加・名前の変更（例: 楽天カード、PayPay）
- 記録をすべて JSON で書き出す

## 知人に使ってもらうとき（管理者向け）

1. 使う人のメールアドレスを許可リストに入れる（Supabase の SQL Editor で実行）
   ```sql
   insert into private.allowed_emails (email) values ('相手のメールアドレス');
   ```
2. 相手に URL `https://asih-collab.github.io/cashflow-app/` と、上の「最初の 1 回だけ」の手順を伝える
3. 伝えておくこと
   - 記録（金額・カテゴリ・メモ）は管理者の Supabase に保存され、**管理者は見ようと思えば見られる**
   - 他の利用者の記録は互いに見えない（データベース側で制限）
   - 1 週間誰も使わないと Supabase が一時停止し、次に開いたとき同期に少し時間がかかることがある
4. ログイン用のメールは Brevo（外部のメール送信サービス、無料枠 1 日 300 通）から送っている。差出人が Gmail なので迷惑メールに入りやすい。相手に「届かなければ迷惑メールを見て」と伝える
