# cashflow-app

個人向けの支出管理・キャッシュフロー最適化アプリ。支払った直後に **金額 → カテゴリ → 保存** の 3 タップで記録し、開けば今月いくら使ったかが見えます。

- iPhone の Safari で開き「ホーム画面に追加」して使う PWA（オフラインでも記録できる）
- データは端末内（IndexedDB）に保存し、ログインすると Supabase に自動で同期・バックアップ
- 公開先: GitHub Pages（`main` への push で自動公開）

使い方は [`docs/使い方.md`](docs/使い方.md)、開発の案内は [`CLAUDE.md`](CLAUDE.md)、決定の記録は [`docs/決定記録.md`](docs/決定記録.md) を参照。

要件定義（家計の数字を含む）は別の非公開リポジトリにあり、このリポジトリには個人データを含めません。
